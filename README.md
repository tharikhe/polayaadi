# Polayaadi VS Code Extension

Polayaadi is a fun VS Code extension that adds some flair to your coding experience by playing iconic Malayalam dialogues when errors occur in your code or terminal!

## Features

- **Syntax Error Feedback:** Plays a classic audio snippet when syntax errors or linter errors are detected in your workspace.
- **Terminal Error Feedback:** Plays another audio snippet when a process in your terminal exits with an error or a task fails.
- **Hello World Command:** Try the `Polayaadi: Hello World` command to check if the extension is working.

## Requirements

Ensure you have basic audio playback capabilities on your OS:
- **Windows:** Uses PowerShell (pre-installed).
- **macOS:** Uses `afplay` (pre-installed).
- **Linux:** Requires `ffplay`, `mpg123`, `paplay` or `aplay` to be installed.

## Extension Settings

This extension currently does not require any specific settings.
